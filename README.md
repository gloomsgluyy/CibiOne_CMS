# CibiOne CMS

Next.js 15 scaffold untuk CMS SMKN 1 Cibinong.

## Mulai

```bash
npm install
npm run dev
```

## Aturan Kerja

- Baca `docs/context/AI_CONTEXT.md` sebelum edit.
- Buat SRS di `docs/srs/<halaman>/<section>.md` sebelum coding section.
- Cek `docs/context/component-registry.md` sebelum membuat UI.
- Dynamic list pakai `ContentList`; singleton pakai `SiteSetting`.
