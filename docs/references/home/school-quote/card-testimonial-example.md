# Card Testimonial Reference

Reference supplied by the user for the quote card between Principal Greeting and Achievement Highlight.

Key visual traits used:

- White testimonial card on a contrasting section.
- Five-star rating.
- Opening and closing quote icons.
- Author avatar, name, and role aligned at the bottom right.

Implementation deliberately uses one semantic component instead of the reference's context/CVA compound-component API because this page currently has one static quote.
