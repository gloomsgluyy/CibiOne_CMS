# Expandable Event Card Reference

Reference supplied by the user: a compact event card backed by compound expandable primitives, Motion transitions, and collapsed/expanded content states.

Adaptation:

- Click activation supports desktop and mobile consistently.
- Collapsed state exposes date, title, time, and urgency.
- Expanded state exposes location, description, and detail link.
- Mobile shows one event per page; desktop shows three.
- Native Motion `height: auto` removes the need for an additional measurement dependency.
